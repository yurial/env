Перед выполнением любой задачи в проекте, если в корне репозитория существует файл `README.md`, прочти его целиком.
Корень репозитория определяй через cwd: `git -C <cwd> rev-parse --show-toplevel`; ищи README.md только в этом toplevel, например `find "$(git -C <cwd> rev-parse --show-toplevel)" -maxdepth 1 -name README.md`, не спускаясь в node_modules и vendor-поддиректории.
Актуализируй README.md в тех местах, где описание затрагивается изменениями текущей ветки: документируй в README то, что меняешь в рамках задачи; в остальном README.md не меняй без явной просьбы.
